# Refero Styles - DESIGN.md Library

This repository contains a curated collection of `.md` design files sourced from [Refero Styles](https://styles.refero.design). 

## 🎨 Overview

Refero Styles provides a comprehensive library of design system documentation tailored for AI agents, developers, and UI/UX designers. These files capture the core design aesthetics and tokens of top, real-world websites and applications, including:

- **Colors:** Primary, secondary, background, text, and accent palettes.
- **Typography:** Font families, sizes, weights, and line heights.
- **Spacing:** Layout grids, paddings, and margins.
- **Component Patterns:** Reusable UI elements, styling rules for buttons, inputs, and structural components.

## 🚀 Usage

This collection serves as a direct knowledge base for rapidly adopting or drawing inspiration from the visual language of high-quality web applications.

- **For AI Agents:** Provide these `.md` files as context to an AI coding assistant to instantly adopt a specific design system for generated frontend code.
- **For Developers:** Reference these files to build accurate CSS variables, Tailwind configurations, or component libraries matching a desired style.
- **For Designers:** Explore and analyze how top tech companies structure their visual tokens.
