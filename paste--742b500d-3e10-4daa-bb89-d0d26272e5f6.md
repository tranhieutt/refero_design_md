## Do's and Don'ts

### Do
- Use 100px border-radius for ALL buttons, badges, and pill-shaped elements â this is non-negotiable and defines the visual identity
- Alternate page sections between #ffffff and #f5f5f7 backgrounds to create rhythm without visible dividers
- Set display headlines (40px+) in system-ui weight 600-700 with negative letter-spacing (-0.7px to -1.04px) â tight tracking at large sizes is essential
- Reserve the amber-orange gradient (rgb(240,100,19) â rgb(254,171,48)) for brand mark and occasional headline accents â never for backgrounds or large surfaces
- Keep all CTA buttons in #0088ff with white text â the warm brand / cool CTA temperature split is the core interaction pattern
- Use #6e6e73 or #ababb0 for secondary/body text to maintain the high-contrast headline / low-contrast body hierarchy
- Apply the soft ambient shadow (rgba(16,16,16,0.1) 0px 0px 30px) to elevated cards â never sharp directional shadows

### Don't
- Never use the amber-orange gradient as a button fill â it is reserved for the logo and decorative headline accents only
- Never mix sharp-corner containers (0px radius) with the pill-radius system â minimum radius for any container is 8px, with 16-20px for cards
- Never use more than one chromatic accent color (#0088ff) in a single CTA context â the four category colors (#34c759, #cb30e0, #ff383c) are for indicators, not buttons
- Never set body text in weight 700 â reserve 700 for headlines at 40px+; body stays at 400-500
- Never add visible border lines between sections â use background color shifts (#ffffff â #f5f5f7) and spacing instead
- Never use directional or hard-edged shadows â the only shadow in the system is the ambient 30px blur at 10% opacity
- Never apply positive letter-spacing to headlines â display type always uses negative tracking; positive spacing is only for small (14-18px) labels

## Layout
Max-width ~1200px centered container. Hero is full-width white with centered headline, centered body text, and a composed multi-device product screenshot below. CTA button centered below body copy. Sticky navigation bar at top with logo left, links center, CTA right. Below hero: a thin press-logos bar (social proof). Sections alternate between #ffffff and #f5f5f7 backgrounds with 80-120px vertical gaps. Feature sections use large amber-gradient headlines centered, followed by explanatory content. Content is predominantly centered single-column â no sidebars, minimal multi-column grids. Section rhythm: hero â social proof â feature intro (amber headline on gray) â feature details â next feature section. The page reads as a vertical scroll with clear section breaks via background shifts.

## Gradient System

The amber-orange gradient (linear-gradient(0deg, rgb(240,100,19) -29.375%, rgb(254,171,48) 100%)) is the singular brand gradient. It appears in exactly two contexts: (1) the logo icon as a background fill, and (2) large display headlines via -webkit-background-clip: text to create gradient text. It is NEVER used as a section background, button fill, or decorative element. The gradient flows from deep burnt orange at the bottom to golden amber at top â when applied to text, it creates a warm metallic shimmer effect. No other gradients exist in the system.

## Category Color System

Four vivid chromatic colors are used as feature-category indicators, applied as text color or border accents on body-level elements â never as backgrounds or button fills:
- Blue (#0088ff): productivity/general features
- Green (#34c759): privacy and security features
- Magenta (#cb30e0): collaboration features
- Red (#ff383c): power/advanced features
These colors mirror Apple's SF Symbols palette, reinforcing the native-OS aesthetic. They appear at body text scale (16-18px) only.
